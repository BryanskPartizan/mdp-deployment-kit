# Сценарий потери worker-узла

1. Подтвердить, что deployment API и Gateway имеют не менее двух реплик.
2. Запустить непрерывные запросы к Gateway.
3. Выполнить cordon и drain одного worker-узла.
4. Зафиксировать переразмещение pod на оставшиеся worker-узлы.
5. Подтвердить сохранение доступности приложения через ingress.
6. Проверить события и метрики в Grafana и через `kubectl get events`.
