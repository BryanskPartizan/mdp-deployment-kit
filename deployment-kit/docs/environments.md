# Окружения

Каталог `environments/` содержит параметры конкретных окружений и провайдеров.

## vm-dev
Основное демонстрационное окружение, используемое для практической части ВКР.

## vm-stage
Стендовое VM-окружение с увеличенными параметрами и stage-специфичными доменными именами.

## aws-stage
Структурный шаблон, показывающий, как тот же подход к развертыванию может быть в дальнейшем адаптирован к облачному провайдеру без изменения общей модели репозитория.
