# Концепция резервного копирования и восстановления

В репозитории реализован демонстрационный механизм резервного копирования PostgreSQL на базе CronJob и PVC. Его задача заключается не в построении промышленного backup-фреймворка, а в подтверждении того, что deployment kit включает отдельный механизм защиты данных для основного stateful-компонента прикладного контура.
