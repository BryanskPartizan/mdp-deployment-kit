# Обзор

Deployment kit представляет собой переносимый репозиторный продукт, стандартизирующий подготовку инфраструктуры, сборку кластера, установку платформенных сервисов и развертывание приложений.

Его практическая ценность заключается в замене фрагментированного Docker-ориентированного подхода на воспроизводимый поток развертывания платформы на базе Kubernetes.
