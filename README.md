# mdp-deployment-kit

Данный проект является магистерской ВКР по направлению "DevOps-инженерия".

## Структура

- `deployment-kit/` — основной deployment kit: Terraform, Ansible, Kubernetes manifests, Helm values, приложения-заглушки, тесты и рабочая документация.
- `deployment-kit/docs/` — актуальная документация по архитектуре, подготовке, запуску, эксплуатации и тестированию.
- `deployment-kit/diagrams/` — актуальные Mermaid и PlantUML диаграммы архитектуры и процессов.
- `execution-log/` — оформленный отчет о практическом тестировании deployment-kit по материалам полного журнала запуска.

Начинать чтение рекомендуется с `deployment-kit/docs/README.md`.
